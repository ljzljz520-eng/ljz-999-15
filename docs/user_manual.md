# FAQuery 用户手册

## 1. 系统简介
FAQuery 是一个轻量级的固定资产查询系统。它允许用户通过输入服务器 IP 和固定资产编码 (FACode)，快速获取对应的序列号 (SN)。系统支持多环境数据库切换，适用于同时也管理开发、测试及生产环境资产数据的场景。

## 2. 快速开始

### 访问系统
在浏览器中输入部署地址（通常为 http://localhost:3000）即可访问系统。

### 核心功能

#### 2.1 资产查询
1. **服务器 IP**: 输入目标数据库所在的服务器 IP 或域名（默认 `localhost` 指向内置数据库）。
2. **固定资产编码**: 输入需查询的 FACode（如 `FA001`）。
3. **查询**: 点击“查询 SN”按钮。
   - **成功**: 显示绿色的结果卡片，包含 SN 码。
   - **失败**: 显示红色的错误提示，包含具体原因（如“未找到”或“连接超时”）。

#### 2.2 设备详情与维修历史 (V7 新增)
查询成功后，结果区会展示该设备的完整档案：

- **资产基础信息**: 设备型号、资产类别、采购日期、保修截止日期，以及两个状态徽章：
  - **保修状态**: 在保（绿）/ 已过保（灰）/ 保修未知。
  - **设备状态**: 闲置 / 使用中 / 维修中 / 已报废。
- **领用提示**:
  - 绿色「可正常领用」：设备闲置且无未关闭维修单。
  - 红色「不可领用」：设备维修中、已被领用、已报废，或仍挂着未关闭的维修单。**维修中的设备不会显示为可领用**，请勿发放。
- **维修历史**:
  - **未关闭问题**: 黄色警示区置顶展示，含严重程度标记（低/中/高/严重）。
  - **最近维修单**: 最多显示 5 条，含报修问题、维修备注、维修人、报修与关闭时间。
  - **换过的部件**: 表格展示部件名称、部件序列号、更换日期及关联维修单号。

> 若查询的是旧版外部数据库（无维修相关数据表），页面只显示 SN，不出现上述区块，属正常现象。

#### 2.3 导出查询结果 (V7 新增)
查询结果页底部提供导出功能。为避免使用人员混淆，**资产基础信息与维修备注分别导出为两个独立的 CSV 文件**：

1. **导出资产基础信息 (CSV)**: 编码、SN、型号、类别、采购日期、保修状态、设备状态、是否可领用。
2. **导出维修记录 (CSV)**: 分三段——最近维修单（含维修备注）、部件更换记录、未关闭问题。

文件均已做 Excel 中文兼容处理（UTF-8 BOM），下载后可直接用 Excel 打开。

#### 2.4 历史记录
系统会自动记录最近的 20 条查询历史。
- **查看**: 首页下方“查询历史”区域。
- **重用**: 点击历史记录条目，自动填充 IP 和 FACode 到上方表单。
- **删除**: 点击条目右侧的垃圾桶图标可删除单条记录。
- **清空**: 点击标题栏右侧的“清空历史”可删除所有记录。

## 3. 高级功能：数据库连接管理

点击页面右上角的 **齿轮图标** 进入管理界面。

### 3.1 默认连接
系统内置一个“系统默认数据库 (MySQL)”，直接连接到 Docker 容器内的 MySQL 实例。该连接不可删除，确保系统总有可用数据源。

### 3.2 新增连接
如需查询外部数据库（如生产环境）：
1. 点击 **"+ 新增 MySQL 连接"**。
2. 填写连接信息：
   - **名称**: 给连接起个名字（如“生产库”）。
   - **主机/端口/用户/密码/数据库名**: 据实填写。
   - **快速填充**: 支持粘贴 `mysql://user:pass@host:port/dbname` 格式字符串，点击“解析”自动填表。
3. 点击 **创建连接**。
4. 在列表中点击 **启用**，即可切换当前查询的数据源。

> **⚠️ 注意**: 新增连接需配置 Public (公网) 可访问的生产环境数据库。

## 4. 常见问题排查

**Q: 点击查询没有反应？**
A: 请检查是否有红色的错误提示框。如果浏览器依然弹出英文气泡，请尝试强制刷新页面 (`Ctrl+F5`) 以更新到最新版本。

**Q: 只有 HTTP 400 错误？**
A: V6 版本已修复此问题，系统现在会显示具体的错误原因（如 "Access denied"）。请根据提示检查用户名密码是否正确。

**Q: 什么是 Public 数据库？**
A: 指可以通过互联网或当前网络环境直接访问的数据库。如果您的数据库在内网，请确保 FAQuery 部署服务器也在同一内网，或已配置 VPN/隧道。
